The optional serial console can send commands to ESP32 firmware; supported commands may control a TV over ADB. Review commands before sending. This page does not connect directly to ADB, and a downloaded CSV is not a TV import format.

ESP32 console over USB serial Connect to the ESP32's UART console to send firmware CLI commands. The browser does not open a direct connection to the TV. 
Console output will appear here after connecting.

Choose the ESP32's USB serial port in the browser prompt. The default baud rate is 115,200. Close any other serial monitor first. The TV export requires the Android TV ADB firmware, a connected TV (tv-connect <host> [port]), Android TV Companion 0.8.0, and its READ_TV_LISTINGS permission. The export request is read-only; it creates a CSV in the TV's Downloads folder and transfers it here over USB.
